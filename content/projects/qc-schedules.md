QC Schedules brings Queens College course listings and historical grade distributions together.

## Project links

- [Open QC Schedules](https://qcs.danncd.com)
- [View the source](https://github.com/danncd/qc-schedules)

## How it works

Python scripts collect and clean course schedules and grade data, then update a Postgres database through Supabase. A Next.js frontend makes the information searchable.

The project uses TypeScript, React, Tailwind CSS, Python, and Supabase. It is an independent project, unaffiliated with Queens College or CUNY.
