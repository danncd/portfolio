## Coding

I build web applications, desktop software, and tools that solve problems I encounter or help me explore new ideas.

These projects range from running coding agents locally and making college course data easier to explore to organizing anime, experimenting with colors, and improving how Minecraft renders item frames.

## Projects

- **Arx** — A desktop coding agent that runs local models and uses tools for coding, web research, and media generation.
- **QC Schedules** — A Queens College course explorer that combines schedules, enrollment information, and historical grade distributions.
- **Anime List** — A macOS app for browsing anime and manga through AniList and organizing titles into personal lists.
- **Palettes** — A browser-based tool for generating, refining, and exporting color palettes.
- **Item Frame Cache** — A client-side Minecraft mod that keeps previously seen item frames visible when the server stops tracking them.
